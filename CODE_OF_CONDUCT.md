# Contributor Covenant Code of Conduct

We pledge to make participation in **Kintsugi Harness** a harassment-free, welcoming, and technically rigorous experience for everyone.

## Standards
- Focus critiques on code, determinism, benchmarks, and reproducibility—never personal attacks.
- Respect maintainers' and contributors' time by verifying `kintsugi verify-ledger` and tests before submitting pull requests.
- Report unacceptable behavior via GitHub repository security/moderation channels.
