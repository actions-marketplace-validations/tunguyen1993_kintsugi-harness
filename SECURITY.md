# Security Policy

## Supported Versions

| Version | Supported |
| :--- | :--- |
| `0.1.x` | Yes |

## Reporting a Vulnerability

Please **do not** open public issues for exploitable ReDoS patterns, hook bypasses, or prompt-injection escapes in `kintsugi-harness`.

Use GitHub's **Report a vulnerability** button under the repository's **Security -> Advisories** tab so we can ship a verified patch and credit your disclosure responsibly.
